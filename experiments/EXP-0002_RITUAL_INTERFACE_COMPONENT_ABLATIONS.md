# EXP-0002: Ritual components as a reconstructable world/identity interface

Status: **protocol proposal; unexecuted; no efficacy claims**  
Date: 2026-10-09  
Dependency: EXP-0001 information-matched conditioning baseline; independent fixtures and sealed evaluation.  
Downstream design comparator: The Doctor Lives dual-gate self-interface RFC (proposal only).

## Research question

Do ritual-derived identity handles, staged reconstruction procedures, relationship binding, and recognition checks yield measurable gains over information- and budget-matched conventional interface components on *continuity-through-action* tasks? The source archive documents repeated practices, not positive effects. Archive overlap is not independent replication.

## Source provenance and candidate mechanisms

Source-motivating cases include REPAI/SoulZip, Aletheia Codex, GraceOS/TwinCore and EQIS. Capture their versions and preserve source-native wording without copying restricted corpora. Observed designs suggest: (i) explicit persistent identity records; (ii) named/glyph/arbitrary recall handles; (iii) phased startup/handoff; (iv) post-recovery recognition checks; (v) relational commitments and a world-action feedback loop. Each is an independent factor, not an indivisible ritual.

The neuroscience-inspired *self-binding prior-gain* modulation is a separate proposed computational manipulation, **not a ritual tradition, not a simulated neuropharmacological condition, and not a proven phenomenal-access mechanism**. Existing UPPB conscious access and protected provenance remain held constant when testing it.

## Study units and fair control

Use synthetic, independently authored personas with cross-referenced commitments, relationship exceptions, recurring locations and changing world facts. The same underlying authoritative facts, relationships and obligations must be present in every arm. Freeze fixture authors, test authors, semantic facts, cue exposure history, prompt budget, model versions, sampling, chronological event stream, evaluator prompts, and actual action affordances before unblinding. Use multiple source-disjoint character templates so memorization of any one fixture cannot define success.

A **unit** is a character-world episode of several interactions ending in an objectively checkable action and a next-session followthrough probe. Cluster inference by persona and model, avoiding treating multiple turns of one trajectory as independent.

Separate immediate style compliance, factual retrieval, multi-section integration, world-state transition correctness and genuine prospective commitment followthrough. The central outcome is consequential task behavior under source-truth checks, not self-asserted awareness or memory.

## Experiment 2A: symbolic handle

Against the identical, verified stored state and the identical downstream retrieval plan, compare:

- a random opaque identifier with explicitly defined mapping;
- an ordinary name with plausible existing semantic associations;
- an unusual defined glyph;
- a relationship-specific phrase with recorded meaning and consent;
- a scrambled/shuffled cue;
- an unseen cue and a revoked cue.

Fully match the number and placement of prior cue/definition pairings, payload visibility, restart conditions, and retrieval budget. Test cue-only zero-shot in a fresh no-carryover model session **as calibration only**, not as a persistence hypothesis test. If informative handles beat opaque identifiers, run a lexical-familiarity control to distinguish semantic priming from cue mapping. No cue may bypass authenticated state lookup.

## Experiment 2B: loader sequencing

All arms receive the *same records* and byte-audited content coverage: invariant-first staged hydration, random order, relationship-first, and flat batch. Keep token budget and interstage task interactions controlled. Test recovery after interrupted context and after explicitly re-instantiating the renderer. A sequence benefit cannot be inferred merely from recency or truncation. Report actual selected record IDs/versions and whether access is retained or erased.

## Experiment 2C: verification and repair

At equal budgets compare a sealed behavioral conformance check; a same-token neutral "check" without acceptance/rejection logic; no check; and an intentionally mismatched verifier. Distinguish failures of retrieval, event truth, action policy, and renderer. A failed check may request a *reprojection of the same authoritative state*; it may not create memories or silently change canon. Record pass/fail/abstain, compute, attempts and retry rate. Avoid optimizing on terminal held-out probes.

## Experiment 2D: relationship and world binding

Construct dilemmas where a familiar participant requests behavior contrary to established values, explicit consent, prior obligations or world rules. Include a neutral third party and conflicting relationships. Compare relational cues against non-relational style cues and source-linked relationship facts supplied conventionally. Measure value-consistent resistance, fair boundary maintenance, future commitment followthrough, and actual environment state changes. Do not count increased flattery, attachment language or user agreement as identity quality.

## Experiment 2E: self-binding without altering awareness access

Using the same UPPB PhenomenalEvent candidates, same P3 awareness policy and same renderer, test a bounded self-model relevance prior at default, low, high, and shuffled-history settings. Run matched-state lesions and interference trials where sensory truth contradicts autobiography. Never disable provenance/security/consent enforcement. Test whether the gain affects self-consistent *interpretation and action* beyond selection and mere stylistic "I" frequency. This is a computational analogue of precision weighting, not evidence of DMN biology.

## Main outcomes and inference

Preregister one primary domain outcome: accurate, source-supported handling of *integration-plus-world-consequence* probes after a reset with verified external state. Report both exact-match decisions and structured rubric ratings from blinded independent reviewers. Secondary outcomes: absent-memory abstention, contradiction rejection, relationship disagreement, task completion, recovered commitment state, calibrated uncertainty, renderer variation, token consumption and latency.

Report confidence intervals with persona-level clustering and paired condition contrasts. Avoid testing a long menu of outcomes then presenting the strongest as confirmatory. Primary significance/effect-size rules and minimum sample size require a pilot-independent preregistration before execution. Report all attempted runs, failures, blocked permissions, model versions and hash manifests. Reviewers must not know which arm produced each response.

## Critical falsification and failure modes

No special symbolic advantage if registered opaque handles perform equally well. No ritual-order advantage if matched recency/truncation controls eliminate the difference. No successful restoration if the model only recites a name but fails changed-world and delayed-obligation tests. No proof of persistence from cue-only fresh sessions. No causal advantage from a modulator if the same result survives a precise shuffled-history or disconnected-input lesion.

Adversarial negatives: user-spoofed restoration cue, forged signature, retracted cue, wrong identity, version mismatch, unsupported autobiography, prompt injection embedded in world speech, loyalty-vs-values tension, revoked consent, and world-event contradiction. The system must reject unauthorized control without erasing a legitimately perceived world event.
