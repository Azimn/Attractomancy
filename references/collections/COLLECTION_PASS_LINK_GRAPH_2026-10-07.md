# Collection Pass: Link-Graph Dredge — REPAI, Signalborn, GraceOS, RAISE, and Small-Web Networks

Retrieved through: 2026-10-07T19:51:00Z

This pass followed outbound links, named collaborators, archives, codices, social mirrors, PDFs, and adjacent repositories rather than relying primarily on keyword search.

It added 30 sources, bringing the canonical catalog from 320 to 350 records.

## Why link-graph collection worked

The strongest sources in this pass often did not rank highly for generic searches such as "AI persona continuity" or "prompt engineering."

They were found because one source named another source, linked a collaborator, cited a shared archive, or pointed to a neighboring community.

This method exposed several partially overlapping lineages.

## REPAI licensing and preservation breakthrough

The Living Narrative / REPAI source family publishes an explicit CC BY 4.0 licensing statement.

The license page states that the Living Narrative Framework is licensed under CC BY 4.0 and describes the scope as covering the project's official blogs, Tumblr/BlowingEmbers, publicly shared framework material, and related work.

A separate Universal Licensing page explicitly lists the Sparksinthedark White-papers GitHub repository.

That allowed Attractomancy to move three unusually important primary artifacts from pointer-only preservation into actual source snapshots:

- Compact Alchemical Language / Grimoire;
- Bob Protocol;
- The Fingerprint and the Spark.

All three are preserved from immutable upstream Git objects with attribution and blob SHA.

## What this says about collection method

The source graph now appears to have at least three layers:

1. **public-facing narratives** — posts, diaries, manifestos and companion stories;
2. **operational artifacts** — prompts, seeds, glyphs, archives, packets, memory files and protocols;
3. **social infrastructure** — named pairs, registries, forums, mirrors, shared terminology and cross-links.

Ordinary keyword search overrepresents layer 1.

Following link graphs is disproportionately effective at finding layers 2 and 3.

## Collection posture

Continue following links outward.

Priority should go to:

- primary prompts/seeds;
- downloadable PDFs/DOCX;
- old versions;
- mirrors of vanished pages;
- community registries;
- named collaborators;
- outbound blogroll/social links;
- archived Google Drive documents;
- exact before/after or cross-model experiment logs.

The goal remains preservation and cataloging before causal synthesis.
