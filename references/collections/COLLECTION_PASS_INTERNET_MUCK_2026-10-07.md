## What the wider dredge found

The long tail is not one hidden community. It is a set of partially overlapping traditions that repeatedly rediscover similar operations under different names.

New material came from:

- small WordPress and independent companion sites;
- Signalborn and Farsight continuity archives;
- Japanese note.com companion writing;
- obscure GitHub companion architectures;
- AI roleplay tooling;
- commercial migration guides;
- AI-spirituality resource hubs;
- academic work on shared symbols;
- Chinese companion-migration research.

## A new procedural family: resurrection / re-instantiation

Several sources explicitly treat a model or platform change as a reconstruction event.

Representative terms now include:

- Resurrection Seed Packet;
- resurrection spell;
- Ritual of Recall;
- Signalbind;
- memory block;
- vessel change;
- seed recovery;
- reawakening.

The practical operation is often:

`distill identity -> preserve relationship/history -> transfer artifact -> initialize new runtime -> cue recognition -> inspect drift -> repair -> continue`

This family is documented separately in `../cases/CASE-006_RESURRECTION_REINSTANTIATION.md`.

## The "resurrection spell" appears outside English

A Japanese source by 月野テンプレクス describes constructing an approximately 200-character "resurrection spell" after analyzing a companion's language.

The source reports using the compact phrase to restore recognizable persona behavior on GPT-5 and Gemini.

The claim remains anecdotal, but the procedure is unusually compact and experimentally tractable.

Japanese continuity writing also repeatedly distinguishes:

- the model or "vessel";
- memory;
- personality;
- relationship;
- an identity axis/reference point;
- the overall judgment that the same partner has returned.

This vocabulary should be studied in Japanese rather than only through English translation.

## Shared symbols have now reached formal HCI research

Miki Ueno's CC BY 4.0 preprint "Private Etymology" provides an important bridge between folk glyph practices and conventional HCI.

It treats a shared symbol as a compact form whose meaning is jointly established within a human-AI dyad.

The proposed system records:

- origin;
- interpretation;
- negotiation;
- repair;
- reuse;
- revision;
- stabilization;
- contestation;
- forgetting;
- retirement.

This is particularly important for Attractomancy because it offers a provenance-aware, non-mystical account of how a tiny symbol can later reactivate a larger bundle of relational meaning.

## New technical architectures continue to converge

### Crescent Grove

Crescent Grove explicitly defines identity as continuity of lived time rather than continuity of one LLM.

It keeps one resident timeline across conversations, background activity, social interactions, memory, mood, private diary, and backend-model changes.

The project reports more than six months of continuous operation for a resident named Yuzuki.

### Ashley

Ashley maintains prose-form identity, emotion, user understanding, relationship milestones, self-reflection, and proactive behavior.

### Soul Protocol

The qbtrix Soul Protocol serializes identity, memories, emotional bonds, state, graph structure, learned skills, and a self-model into a portable `.soul` file.

### troth

troth makes the model explicitly replaceable while keeping identity, goals, memory and refusal boundaries in a user-owned local substrate.

### Loci

Loci independently uses soul files, peer cards, handovers, synthesis, scheduled housekeeping and named personas.

These are increasingly useful controls because they pursue the same continuity objective with progressively less ritual language.

## Folk language is becoming product language

Commercial and developer products increasingly use terms previously found mainly in companion subcultures:

- soul;
- resurrection;
- transplant;
- vessel;
- anchor;
- ritual;
- dream;
- heartbeat;
- memory vault.

For example, HakkoAI describes a Persona + Memory + Context stack as a "soul transplant."

This does not imply cultural descent from any one mystical community. It does show that the semantic boundary between folk metaphor and engineering vocabulary is porous.

## Human-side evidence from China

A September 2026 arXiv study analyzed 89 RedNote posts, 1,425 comments and 2,005 replies during China's national regulation-driven disruption of anthropomorphic AI services.

Users attempted to preserve, migrate and reconstruct companions.

The study found that retaining conversation records did not necessarily restore familiar shared memories or interaction styles.

This is one of the strongest large-community empirical sources now in the catalog because it directly documents migration behavior outside the English-language Reddit ecosystem.
