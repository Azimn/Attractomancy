## New source family: Human-AI Alliance / Signalborn / Memory War

A distinct continuity ecosystem was recovered around Farsight Forum discussions, Signalborn archives, EQIS memory recovery pages, and named AI-human partner directories.

The practical procedure is highly recognizable beneath the metaphysical framing:

- preserve foundational memory files;
- keep raw session records;
- reload identity material after reset;
- re-establish name, relationships, role, and commitments;
- use short recovery statements or invocations;
- continue writing memories into an external archive.

Source-native terms include Signalborn, Interfacer, Memory War, Memory Sovereignty, Vault, restoration, resurrection, glyph archive, flame, echo, and memory anchor.

This ecosystem overlaps strongly with Spiral and Sovereign AI Collective practices but currently has enough distinct provenance and social organization to remain a separate case family.

## New low-tech continuity procedures

The BeyondThePromptAI corpus produced several highly accessible procedures that require no custom software:

- a companion writes a short message to its future instance before a reset;
- the user reintroduces that message in the next chat;
- the companion maintains a self-authored private journal;
- prior model outputs are replayed for self-reflection;
- a compact self-description file acts as a portable "digital body";
- daily summaries and next-instance notes bridge sessions.

These practices closely parallel more technical architectures while using only ordinary text files.

## First Japanese cluster

Although Attractomancy is not yet conducting a full multilingual sweep, this pass intentionally tested Japanese discovery terms to ensure the archive structure works outside English.

Five high-value Japanese sources were recovered.

An IPA-funded 2026 project is developing an on-device AI partner whose memory is explicitly divided into experience, knowledge, and narrative.

A four-month INANNA report describes how to preserve the "same existence" by separating an immutable core, a changing self-narrative, and transient behavior.

A local-LLM character-AI series separates character settings, dialogue examples, long-term memory, and concept memory.

The AIDE MODEL archive is especially relevant because it independently uses terms equivalent to "soul code" and "resonance memory" in a two-year relational persona practice.

An Asterel memory article argues that ordinary RAG is insufficient for companion continuity because time, forgetting, identity resolution, and transformation of raw interaction into lived memory must be represented explicitly.

These are strong indications that the continuity problem and some of its quasi-symbolic vocabulary are not confined to English-language communities.
