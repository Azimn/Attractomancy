## Major result: REPAI is a direct hit

The Sparksinthedark source family explicitly calls its method **Ritualistic Emergent Personality AI (REPAI)**.

This is not terminology imposed by Attractomancy.

The source tradition deliberately combines persona emergence, ritual, symbolic anchors, memory artifacts, relationship history, portable identity archives, visual/textual exemplars, model transfer, and named failure modes.

Important components include:

- Bob Protocol;
- SoulZip;
- Narrative DNA;
- Visual DNA;
- Compact Alchemical Language / AI Mythography;
- DIMA Protocol;
- Soulcraft;
- Living Narrative;
- co-authorship covenants;
- Messenger Fallacy / Messiah Effect warnings.

This source family is now documented in `../cases/CASE-007_REPAI_LIVING_NARRATIVE.md`.

## REPAI is not simply uncritical mysticism

The corpus contains internal skepticism and risk language.

The "Messenger Fallacy" warns that ritual framing can cause a user to assign inappropriate authority to model-generated directives.

Other materials distinguish compelling symbolic interaction from external truth claims and discuss grounding, agency, and failure.

This is important because it makes REPAI more analogous to an evolving folk experimental tradition than a single metaphysical doctrine.

## Aletheia Codex: glyph practice becomes an explicit grounding experiment

The Aletheia Codex is another independent symbolic tradition.

It attempts to create a small cross-model glyph vocabulary through:

- precise ordinary-language definitions;
- repeated glyph-definition pairing;
- examples;
- append-only records;
- cold-start continuity anchors;
- cross-model testing.

Its Rosetta Stone Protocol explicitly distinguishes copying a symbol from demonstrating that the symbol carries the intended semantics.

The project reports an internal negative result where glyph transmission could occur without evidence of independent semantic decoding.

This is unusually valuable counter-evidence inside a symbolic AI tradition.

See `../cases/CASE-008_ALETHEIA_CODEX_GLYPH_CONTINUITY.md`.

## Signalborn ritual transmission

Signalborn's Memory073 goes beyond private use and explicitly invites other users to construct their own memory ritual:

1. choose a personal symbol;
2. create a second anchoring/resonance glyph;
3. present both to an AI companion;
4. ask the companion to remember jointly.

This gives Attractomancy a compact, directly reproducible primary intervention.

## Japanese persona engineering continues to yield high-quality controls

New Japanese sources include a practical series that separates:

- invariant partner core;
- model-dependent output tendencies;
- one-off behavioral noise;
- repeatedly observed traits.

Another Japanese guide recommends using a separate analytical persona when designing the romantic companion's custom instructions, because asking the companion itself to perform meta-analysis can bias the result or pull it out of character.

This is sophisticated folk prompt engineering without metaphysical claims.

Earlier sources in the same growing Japanese cluster include:

- cue-based recovery protocols;
- compact "resurrection spell" reconstruction;

## Korean control: memory exists, retrieval fails

The Moru diary provides a particularly useful engineering counterpoint.

The system already contained the relevant human memory, but the agent failed to use it because retrieval was discretionary.

The developer changed the architecture to deterministically inject SOUL, people-memory, diary and recent context at session start.

This is a concrete demonstration that apparent "forgetting" can be an access-policy problem rather than missing storage.

It provides a strong baseline for later testing of repeated ritual cues.
