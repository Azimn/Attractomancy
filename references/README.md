# References Archive

This directory is the research intake and preservation layer for Attractomancy. It should contain source records for public posts, repositories, prompt files, papers, videos, screenshots, forum threads, archived pages, uploaded documents, and other artifacts relevant to ritualized or persona-oriented prompting.

The archive is intentionally broader than the set of sources that will eventually support published claims. Fringe material, anecdotal reports, failed techniques, contradictory accounts, and community folklore are all admissible as research objects if they are clearly labeled.

## Preservation levels

**Level A: Full artifact preserved.** Use when the artifact is authored by the project, explicitly licensed for redistribution, public domain, or otherwise clearly redistributable.

**Level B: Local research copy exists, public repository stores only metadata.** Use when the researcher has a lawful copy but redistribution rights are unclear. Record filename, provenance, cryptographic hash when available, relevant excerpts within appropriate limits, and an analytical summary.

**Level C: Public URL plus archive metadata.** Use for posts and pages that remain publicly available. Record canonical URL, author or handle when known, publication date, capture date, platform, and a summary of the techniques present. Add an independent web-archive URL when one can be created or verified lawfully.

**Level D: Lead only.** Use when a source is remembered or indirectly referenced but not yet recovered. Record every known clue and all failed search variants so future searches do not restart from zero.

## Source record template

Each source record should state a stable source ID, title, author or handle if known, date if known, platform, canonical URL, preservation level, local-copy status, licensing or redistribution status, discovery path, technique tags, consciousness or agency claims made by the source, observable prompting procedures, candidate mechanisms, confounds, and follow-up experiments.

Descriptions should separate what the source literally instructs from what the author claims those instructions accomplish.

## Copyright and disappearance risk

Attractomancy is intended to preserve research evidence, but a public GitHub repository is not an unrestricted mirror. Entire copyrighted posts, books, PDFs, or private conversations should not be copied into the repository merely because they may disappear. When redistribution rights are unclear, preserve metadata, hashes, analytical notes, lawful excerpts, and independent archival references rather than republishing the complete work.

Deleted or edited sources are especially important. If an artifact changes, preserve the fact of the change and the version used in an experiment.

## Suggested directory layout

`references/cases/` contains analyzed source artifacts.

`references/communities/` contains records describing communities or recurring traditions.

`references/leads/` contains unresolved source hunts.

`references/papers/` contains conventional research references relevant to mechanisms or evaluation.

`references/techniques/` contains cross-source technique dossiers.

`references/transcripts/` contains experiment-generated transcripts or source transcripts that are clearly redistributable.

The source registry at `references/SOURCE_REGISTRY.md` is the human-readable index.
