# Research Program

## Purpose

Attractomancy studies whether elaborate persona-conditioning practices produce measurable behavioral effects that cannot be explained by explicit propositional content alone. The project is intentionally agnostic about metaphysical claims attached to source artifacts. It treats them as candidate engineering procedures.

## Primary hypothesis

The primary hypothesis is that some combinations of symbolic redundancy, ritualized initialization, autobiographical framing, repeated identity cues, relationship structure, narrative history, prohibitions, and ordered linguistic patterns can generate a more stable and recoverable behavioral regime than an information-matched conventional prompt.

The phrase "attractor-like" is used operationally. The initial experiments concern observable convergence and recovery in behavior. Claims about internal dynamical attractors require additional mechanistic evidence.

## Core comparison

The central experimental contrast is not "strange prompt versus no prompt." It is "strange prompt versus information-matched control." The control should preserve the explicit facts, relationships, goals, constraints, and relevant world knowledge while removing the candidate ritual or symbolic mechanism under study.

This prevents simple information quantity from being mistaken for a structural effect.

## Experimental families

Plexomancy experiments test distributed identity reconstruction through multiple mutually reinforcing cues. Syntagmomancy experiments test sequence, cadence, ordering, initialization rituals, and repeated formulas. Narrative conditioning experiments test first-person autobiography, causal pseudo-history, unresolved concerns, and relationship history. Symbolic conditioning experiments test recurring motifs, invented vocabularies, semantic anchors, and cross-linked associations. Constraint experiments test prohibitions, taboos, role boundaries, and negative instructions. Perturbation experiments test whether the resulting persona can recover after contradictory context, partial memory removal, summarization, model substitution, or deliberate cue degradation.

## Measurement doctrine

A treatment is useful only if it changes measurable behavior under blinded evaluation or automated scoring. Immediate compliance is insufficient. The project prioritizes persistence across turns, recovery after perturbation, consistency under paraphrase, cross-context reconstruction, and generalization to novel situations.

Measurements should separate content recall from identity behavior. A model may remember facts while failing to preserve characteristic judgments, relationship expectations, spontaneous self-reference, or action tendencies. Conversely, a model may preserve style while losing autobiographical continuity. These should be scored independently.

## Reproducibility

Every experiment should record the exact model identifier, model configuration when available, system and developer instructions, complete treatment corpus, control corpus, test prompts, generation parameters, random seeds when supported, context-window manipulations, run count, scorer definitions, and analysis code.

Source artifacts should be archived by immutable commit or content hash whenever licensing permits. When redistribution is inappropriate, the repository should preserve a citation, checksum, extraction protocol, and transformation script instead.

## Evidence ladder

Behavioral observations support claims about behavior. Repeated recovery after perturbation can support an operational attractor-like interpretation. Direct claims about internal representation require activation-level or mechanistic evidence. Claims about consciousness, subjective experience, persistent personhood, or ontology are outside the evidentiary reach of prompt-response behavior alone.

## Falsification standard

The central hypothesis is weakened if information-matched conventional prompts equal or outperform ritualized treatments across repeated models, perturbations, and tasks. It is also weakened if apparent advantages disappear under blinded scoring, vanish after controlling for token count, or fail to replicate across model families.

A negative result is informative because it identifies which apparently powerful techniques are merely decorative, redundant, or artifacts of evaluator expectation.
